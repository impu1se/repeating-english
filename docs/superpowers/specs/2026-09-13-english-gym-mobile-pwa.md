# English Gym Mobile — дизайн-спека (PWA для iPhone)

**Дата:** 2026-09-13
**Статус:** согласовано (grilling-сессия, 13 решений)
**Реализующий план:** `docs/superpowers/plans/2026-09-13-english-gym-mobile-pwa.md`

## Цель

Превратить существующий статический React-SPA «English Gym» в устанавливаемое
на домашний экран iPhone приложение (PWA), которое работает полностью офлайн,
корректно ведёт себя с экранной клавиатурой iOS и не теряет прогресс.

Нативная обвязка (Capacitor, App Store, платежи) — **следующий этап**, но код
этого этапа должен переиспользоваться в ней на 100%: Capacitor оборачивает тот
же `dist/`, React-код не переписывается.

## Решения

### Инфраструктура

1. **Аудитория.** Приложение для одного пользователя (автора). App Store и
   продажа контента — отложены, но мост не сжигаем: путь PWA → Capacitor.
2. **Технический путь.** PWA сейчас. React Native не рассматривается (это
   переписывание UI-слоя). Capacitor позже.
3. **Хостинг.** GitHub Pages, публичный репозиторий под аккаунтом `impu1se`.
   Открытые исходники приняты сознательно: контент всё равно целиком уезжает
   в браузер внутри JS-бандла, приватность репозитория его не защищает.
4. **Уведомления.** Не делаем. Web Push на iOS требует сервера (противоречит
   решению «без бэкенда»), локальных уведомлений у PWA на iOS нет.

### Продукт

5. **Типы заданий.** Все семь остаются без изменений. Клавиатура нужна 906 из
   1451 задания (62%), и это не урезается: продуцирование английского —
   основная ценность тренажёра. Форк контента под мобильный не делаем.
6. **Поведение ввода.** Автокоррекция, автозаглавная буква и проверка
   орфографии выключены. Обоснование: iOS молча чинит `dont` → `don't` и тем
   самым обнуляет упражнения на сокращения. Механика «близко» с самооценкой
   «Засчитать?» уже прощает честные опечатки.
7. **Сохранность прогресса.** Экспорт и импорт JSON-файла. В файле есть поле
   версии формата, чтобы будущие профили не сломали старые выгрузки.
8. **Локальные профили (бэклог v3).** В этот этап не входят. На личном iPhone
   профиль по определению один.
9. **Офлайн и обновления.** Кэшируется весь бандл (492 КБ), приложение
   работает офлайн целиком. Новая версия скачивается в фоне и применяется
   молча при следующем холодном запуске — без баннера и без перезагрузки
   посреди тренировки.

### Визуал

10. **Глубина адаптации.** Минимальная: отступы `safe-area`, тап-цели от 44
    пикселей, липкие эффекты наведения убраны, вёрстка не ломается на 320 px.
    Редизайн под системный вид iOS — отдельный этап, когда появятся чужие
    пользователи.
11. **Тёмная тема.** По системной настройке, через `prefers-color-scheme`.
    Переключателя внутри приложения нет.
12. **Имя и иконка.** Имя «English Gym». Иконка рисуется кодом в SVG
    (геометрическая гантеля, без зависимости от шрифтов) и растеризуется в
    нужные размеры отдельной командой `npm run generate-pwa-assets`, а PNG
    коммитятся в репозиторий. Растеризатор намеренно не входит в сборку и CI:
    он тянет бинарную зависимость ради файлов, которые меняются раз в год.
    Плата за это — после правки `public/icon.svg` PNG надо перегенерировать
    руками, иначе они останутся старыми и никто об этом не скажет.
13. **Критерий готовности.** Чеклист проходит на живом iPhone автора.

## Поправки к ранее сказанному

- **Блокировки ориентации в PWA на iOS не существует.** Safari игнорирует поле
  `orientation` в манифесте. Вместо блокировки: вёрстка не ломается в
  альбомной ориентации. В манифест поле не пишем, чтобы не обещать неправду.
- **Выгрузка файла через `<a download>` в установленном приложении на iOS
  ненадёжна.** Экспорт идёт через Web Share API с файлом, запасной путь —
  копирование JSON в буфер обмена.

## Известные ограничения платформы (учтены в плане)

- Хранилище установленного приложения изолировано от Safari: прогресс,
  набранный в браузере до установки, в приложение не переедет сам. Переносится
  экспортом и импортом.
- Удаление иконки с домашнего экрана удаляет и хранилище приложения.
- Vibration API в Safari отсутствует — тактильного отклика не будет до
  Capacitor.
- `position: fixed` на iOS не отслеживает экранную клавиатуру, поэтому липкая
  кнопка над клавиатурой не обещается: кнопка стоит в потоке сразу под полем,
  плюс `enterKeyHint="go"` для отправки с клавиатуры.
- GitHub Pages отдаёт проектный сайт по подпути `/repeating-english/`, поэтому
  `base` должен быть управляемым из окружения (Capacitor потребует `/`).

## Вне рамок

Capacitor и нативная сборка, App Store, платежи и StoreKit, Android,
уведомления, облачная синхронизация, локальные профили, Playwright, редизайн
под системный вид iOS.

## Критерий готовности

На личном iPhone автора:

1. Иконка «English Gym» стоит на домашнем экране, картинка не заглушка.
2. Запуск полноэкранный, без адресной строки Safari.
3. В авиарежиме тренировка проходится целиком, включая все типы заданий.
4. При вводе ответа iOS не исправляет текст и не поднимает первую букву.
5. Экспорт прогресса выгружается через «Поделиться», импорт восстанавливает
   выгруженный файл.
6. Тёмная тема включается от системной настройки телефона.
7. Вёрстка не ломается ни в портретной, ни в альбомной ориентации.
8. `npm test` и `npm run build` зелёные.
