Здесь все решения, которые я принял сам, пока план выполнялся: конфликты внутри
плана, находки ревью против текста плана и отложенные замечания. Спека была
главнее плана везде, где они расходились. Порядок — тот, в котором решения
принимались. Каждое можно отменить, код к этому готов.

Спека требует хранить замеры в состоянии, значит поля обязательны, а два тестовых литерала — механическая правка. Цена ошибки: нулевая, литералы всё равно пришлось бы править.
- Ruling: конфликт задачи 9 закрыт правкой плана — `src/components/ModuleList.tsx` внесён в список файлов. Цена ошибки: нулевая.

Цена ошибки, если не исправить: первые профили частично уходят в unmapped.
- Task 3: Ruling: `eslint.config.js` получил оверрайд с node-глобалями для `scripts/**/*.mjs` — отклонение от списка файлов задачи, но лint обязан быть зелёным, а это первый node-скрипт в репозитории. Зависимостей не добавлено. Цена ошибки: лишние семь строк конфига.
- Task 3: Ruling: три строки каталога кончаются двоеточием (первая строка теории — зачин перед списком). Оставляем, генератор нарочно тупой. Отложено как minor.
- Task 3: Ruling: правим — план предписал этот код, но спека о нём молчит, а замечание верное: генератор, который вешается вместо падения, дороже одной строки. Цена ошибки: никакой, правка локальная.
- Task 4: Ruling: count и wordCount обязаны быть целыми положительными (`Number.isInteger && > 0`). Infinity из `1e400` — валидный JSON и прошёл бы прежнюю проверку, а в частоте на сто слов он отравил бы все последующие замеры. Цена ошибки: нулевая.
- Task 4: Ruling: битую запись не выбрасываем молча, а отклоняем весь файл с русским сообщением. Файл пишет чат, значит поломку можно переделать, а тихая частичная загрузка её скрывает. `mapped`/`unmapped` остаются единственными двумя счётчиками — из них собирается строка статуса в задаче 7. Цена ошибки, если не прав: чат иногда отдаёт `count: "7"`, и вместо частичной загрузки пользователь получит отказ и просьбу переделать разбор.
- Task 4: Ruling: поднял Minor про `recordedAt` до правки — задача 5 сортирует замеры по этой дате, чтобы считать динамику, и пустая дата дала бы молча неверное «было». Требуем строку вида YYYY-MM-DD. Цена ошибки: нулевая.
- Task 4: Ruling: задача 4 закрылась на 132 тестах вместо 126 — шесть тестов добавил раунд правок. Ожидаемые числа в задачах 5–9 сдвинуты на +6 (139/150/155/160/167), чтобы брифы не сбивали исполнителей. Цена ошибки: нулевая, числа справочные.
- Task 4: Ruling: правим дату круговой проверкой через `Date`. Невозможная дата с месяцем 13 сортируется позже любой настоящей в том же году, то есть один битый замер выдал бы себя за самый свежий и перевернул бы динамику — ровно то, ради чего волна и делается. Цена ошибки: нулевая.
- Task 5: Ruling: сортируем копию по дате внутри обеих функций. Ни `loadProgress`, ни `parseBackup` порядок не гарантируют, а перевёрнутая динамика не просто врёт — она советует бросить ровно ту ошибку, которую надо гонять. Правку держим в этом модуле: он единственный зависит от порядка, а расширение затронуло бы две закрытые задачи. Цена ошибки: одна лишняя сортировка на отрисовку, замеров единицы.
